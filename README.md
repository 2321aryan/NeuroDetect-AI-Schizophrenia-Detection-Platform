# NeuroDetect-AI-Schizophrenia-Detection-Platform
An AI-powered medical diagnostic platform for schizophrenia detection using EEG and MRI data.

## 🚀 Features
- EEG/MRI data upload and analysis
- Deep learning models (TensorFlow/PyTorch)
- Role-based access: Researcher, Doctor, Admin
- FastAPI backend + React frontend
- HIPAA-compliant data handling

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind
- **Backend:** FastAPI (Python)
- **AI Models:** TensorFlow, PyTorch
- **Database:** MongoDB / PostgreSQL

## ⚙️ Setup Instructions
1. Clone repository  
   `git clone https://github.com/aryanparekh/NeuroDetect-AI.git`
2. Install dependencies:  
   - Backend: `pip install -r requirements.txt`
   - Frontend: `npm install`
3. Run backend: `uvicorn main:app --reload`
4. Run frontend: `npm start`
